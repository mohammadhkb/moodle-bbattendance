# Choose a license before public release

This repository does not yet include a project license. Before publishing, choose a license you are authorized to apply to all original code in this repository and check the licenses of any third-party code included.

For Moodle plugins, a GPL-compatible license is commonly appropriate. If you choose GNU GPL version 3 or later, add the complete `GPL-3.0-or-later` license text as `LICENSE` and ensure the plugin code and any bundled third-party code can be distributed under it.
